# Input and output

`metator.io` reads and writes the files of a run: the contig data and cluster
summary tables, FASTA files and indexes. `metator.outputs` names the folders
of the output directory of a run, and writes the FASTA files of its genomes
and MGE clusters and the cool files of its MAGs. `metator.log` holds the
logger every module writes to. [File formats](../formats.md) describes the
files.
