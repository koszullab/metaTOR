# Contact maps

`metator.metacool` writes the contact map of a run, grouped by bin, as a
`.metacool` file, from its pairs or from the map it started from.
`metator.contact_map` builds the contact map of one contig or bin with
hicstuff. See [The contact map of the bins](../guides/metacool.md) and
[Viewing and scaffolding MAGs](../guides/visualisation.md).
