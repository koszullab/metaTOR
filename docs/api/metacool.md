# Contact maps

`metator.metacool` writes the contact map of a run, grouped by cluster, as a
`.metacool` file, from its pairs or from the map it started from, and reads
the contacts of contigs from a map. `metator.contact_map` builds the contact
map of one contig or cluster with hicstuff, or from a map. See
[The contact map of the clusters](../guides/metacool.md) and
[Viewing and scaffolding MAGs](../guides/visualisation.md).
